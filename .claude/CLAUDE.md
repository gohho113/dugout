# DUGOUT 作業ルール

このリポジトリは一般公開しているゲーム DUGOUT（https://gohho113.github.io/dugout/）。`main` に入れたものはすぐ公開される（GitHub Pages）。

## 公開のルール（最重要）

- **修正してすぐ公開しない。** 修正は `dev` ブランチで行い、`main` には入れない
- 直したものは、まずプレビュー（非公開の試せるページ）で作者（ゴッホ）に確認してもらう
- 作者が「公開して」と言ったときだけ、`dev` を `main` に入れて push する
- `style.css` / `script.js` を変えたら、公開するときに `index.html` の `?v=…`（版番号）を新しくする（ブラウザに古いファイルが残らないように）

## そのほか

- 球団・選手・企業はすべて架空。実在の選手・OBの名前そのもの、実在企業の名前そのもの、ロゴは使わない
- 仕様を変えたら `仕様書.md` と `README.md` も直す
- コミットにメールアドレス（仕事用など）を出さない
