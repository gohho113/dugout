# DUGOUT（ダグアウト）

> 仲間が集う場所から、頂点へ。

プロ野球球団の **GM（ゼネラルマネージャー）** になって、選手を集めて育て、お金をやりくりしながら日本一をめざすブラウザゲームです。

- ドラフト会議（くじ引き・外れ1位・育成ドラフト・おまかせ指名）
- 国内FA・海外FA・トレード・現役ドラフト・合同トライアウト
- 1軍登録31人・ベンチ入り26人・コンバート・おまかせオーダー
- 監督・コーチの招へいと解任
- スポンサー営業（特典つき）・ネーミングライツ・球場の移転・設備投資・銀行借入・法人税
- 主力選手を国際大会（世界野球クラシックなど）の日本代表に送り出すかどうかの決断
- プレーオフから日本一決定シリーズまで
- 難易度（やさしい・ふつう・むずかしい）
- はじめに12球団（セントラ・リーグ／パシフィカ・リーグ）から担当する球団を選べる
- 担当する球団の地元の出来事だけが起きる（お祭り・季節の行事・名物グルメ・名所・伝統工芸を各球団10個ずつ）
- 1シーズン15試合。スポンサーが観戦・コラボ商品・CM出演・冠デー・差し入れ・逆オファーなどの出来事で登場し、ホームでもスポンサー一覧が見られる
- ユニフォームのデザイン変更（テンプレート8種・模様・色・胸の文字・パイピング・袖ライン・テールスウッシュなど）。発表するとファンが増えてグッズが売れる。期間限定ユニのイベントも
- 球団公式のYouTube・SNS（登録者が増えると広告収入）、選手のYouTubeデビューやSNS炎上への対応
- シーズン結果の「成績カード」を作ってXにシェアできる
- 1年目は「はじめてのガイド」が案内してくれる
- 選手のドラマ：今季のMVP、ドラフトで取った選手の成長ストーリー、引退試合、背番号の永久欠番、今季の宿敵
- チャレンジモード（資金0から3年で日本一 など5種類）と、毎日変わる「今日のお題」
- PCでもスマホでも遊べる（スマホでは下にタブ、PCでは上にタブ。ホーム・編成・補強・試合・経営・営業・球団の7つ）

細かいルールや数値は [仕様書.md](仕様書.md) にまとめています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要・PC／スマホ対応）。
進行はブラウザに自動で保存されます。セーブデータは3つまで（タイトル画面でスロットを選ぶ。球団タブから別のスロットにコピーも可能）。

## GitHub Pages で公開する

1. このフォルダのファイル（`index.html` / `style.css` / `script.js` / `ogp.png` ほか）をリポジトリの直下に置いて push する
2. リポジトリの **Settings → Pages** で「Deploy from a branch」→ `main` / `/(root)` を選んで保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになる

※ GitHub の無料プランでは、Pages を使うにはリポジトリを **Public** にする必要があります。
※ SNSでURLを貼ったときのカード画像（`index.html` の `og:image`）は `https://gohho113.github.io/dugout/` を前提にしています。公開先を変えたらここも直してください。
